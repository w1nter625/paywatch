PayWatch

If a watched wallet moves more than your cap, a reactive contract records it. No bot to keep online.

Track: Reactive Omni Buildathon · Set It and Forget It

Origin / destination: Ethereum Sepolia (11155111)

Reactive chain: Lasna (5318007)

MockUSD 0x8BE4…227D8 and AlertBoard 0x3638…48Fb47 on Ethereum Sepolia; PayWatchReactive 0x4644…A10A4c8 on Lasna. See the repository README and demo-txs.md.

Demo video (80s, English narration + captions).

The loop

MockUSD.Transfer (Ethereum Sepolia)
        │
        ▼
PayWatchReactive.react (Lasna)
        │
        ▼
AlertBoard.recordAlert (Ethereum Sepolia, via callback proxy)

Source and docs are in the repository README.
